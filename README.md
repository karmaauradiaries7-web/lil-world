# Every Little Thing You Did Deserved to Be Felt ❤️
A cinematic, interactive apology story. Plain HTML, CSS and JavaScript — no build tools, no external APIs, no photos needed.

## Customize
Open `script.js`. Everything personal lives in the `CFG` block at the top: names, every chapter's text, whisper phrases and the music path. A blank line inside a message starts a new paragraph.

## Add your song
Save your file as `audio/our-song.mp3`. Music is off until she taps the music button. Don't use copyrighted tracks if you publish publicly.

## Run locally
Double-click `index.html`, or run `python3 -m http.server` in this folder and open http://localhost:8000.

## Publish with GitHub Pages
1. Create a repository and upload all files (keep the folder layout).
2. Settings → Pages → Deploy from branch → `main` → `/ (root)` → Save.
3. After a minute or two, your link appears: `https://<username>.github.io/<repo>/`.
Direct chapter links: `#conch`, `#star`, `#map`. A public repo means anyone can find the page, so use a plain repo name.

## Story order
Opening → Journey (Jan 5, Apr 6, sales job, September) → Apology 1 → Apology 2 → Conch Shell memory → Lucky Star memory → Promises → Future career journey → Ten-day reveal → Teddy hug. Every chapter is also reachable from the "Story map" button, or by link (`#conch`, `#star`, `#future`, …).
